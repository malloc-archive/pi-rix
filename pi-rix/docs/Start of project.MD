# 기록 시작

멀티이펙터가 비싸니 가지고있는 rpi 4B와 id4MK2 오인페를 멀티이펙터로 개조해보려 한다.
솔직히 ADC,DAC가격 빼곤 다 소프트웨어 값일것이다.
id4mk2 오인페 가격이 왠만한 멀티이펙터 가격을 상회하니 소리는 더 좋을것이라 기대해본다.


# 삽질 시작
qjackctl과 guitarix를 사용해서 오인페를 연결하고, 프리셋을 불러오니 xrun이 발생해 소리가 끊긴다.
48000, 256sample, 3period만 해도 대략 8ms의 latency가 발생하는데 무거운 crunch프리셋을 사용하면 이마저도 끊긴다.

분명 rpi성능이 부족한것이 아닌데 끊기므로 rpi의 firmware를 preempt_rt로 개조해 봐야겠다.
다행이 최근버전 rpi는 preempt_rt가 포함된 펌웨어를 포함한다.
문제는 난 이걸모르고 docker에서 firmware를 빌드하는 삽질을 했다.
결국 다시 돌아와서 config만 바꾼뒤 적용시켰다.

개조 후에도 xrun이 발생해서 확인해보니 jack의 타임아웃은 100us정도고 latency 측정값이 2자리 대이니 분명 성능은 충분하다.

삽질을 좀 해본 결과 RT의 우선순위에 rpi 옛날버전 인터페이스 이름이 적혀있어서 그런것 같다. usb hcpi?로 바꿔주니 128sample에서도 안정적으로 작동한다.
